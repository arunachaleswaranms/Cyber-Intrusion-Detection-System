# ADR 0003: Use bounded model-agnostic SHAP explanations

- Status: Accepted
- Date: 2026-09-12
- Accepted: 2026-09-23

## Context

The first v2.1 spike proposed SHAP `0.52.0` `TreeExplainer` with a deterministic
256-row development background, raw Histogram Gradient Boosting output, and
interventional feature perturbation. Representative models passed, but the
original local binary v2.0 selected artifact failed SHAP's additivity check on
macOS. For one selected validation record, SHAP reconstructed `-9.620861` while
the estimator returned `-9.392511`, an absolute gap of about `0.228350`. This is
far above the project's `1e-5` acceptance tolerance. The gate stopped before the
multiclass task and wrote no success report.

Disabling SHAP's check would not resolve the mismatch because CIDS independently
checks the same conservation property. The official-test targets were never
loaded, and no official-test record was predicted, scored, or explained.

## Decision

Replace the rejected tree-specific route with SHAP `0.52.0`
`PermutationExplainer`, a model-agnostic local explanation method. The fallback
is bounded and deterministic:

- raw estimator decision output;
- an independent 256-row background sampled from prepared training data;
- ten prepared-validation records in the acceptance gate;
- one forward/reverse permutation cycle and seed `42`;
- no more than 32 explanations or 60 seconds per task;
- independent additivity tolerance `1e-5` and aggregation tolerance `1e-10`;
- deterministic aggregation from encoded columns to the 42 source features.

SHAP documents that one forward/reverse permutation cycle guarantees local
accuracy through antithetic sampling. The resulting values remain feature
attributions, not causal claims or calibrated confidence.

## Evidence and status

A representative Python `3.12.14`, SHAP `0.52.0`, scikit-learn `1.8.0` spike at
the v2.0 transformed dimensions produced:

| Task | SHAP value shape | Elapsed | Maximum additivity error |
|---|---:|---:|---:|
| Binary | `10 × 194` | 15.080 s | `1.15e-14` |
| Multiclass | `10 × 68 × 10` | 8.672 s | `3.11e-14` |

Both original selected local artifacts passed on Arun's Apple Silicon Mac:

| Task | SHAP value shape | Elapsed | Maximum additivity error | Maximum aggregation error |
|---|---:|---:|---:|---:|
| Binary | `10 × 194` | 3.930 s | `3.55e-14` | `1.78e-15` |
| Multiclass | `10 × 68 × 10` | 4.293 s | `6.22e-14` | `7.11e-15` |

Both tasks remained below 60 seconds and far inside the `1e-5` additivity and
`1e-10` aggregation limits. The report records
`official_test_status: not_evaluated_by_gate` and confirms that official-test
records were not used as explanation data. The preserved report SHA-256 is
`d6db9aae2368b09b33b22a666d67208e27f28c277a5e613b07aed12e0551f528`.

## Consequences

- The explanation path is slower than TreeExplainer but remains bounded for a
  local analyst workflow.
- Phase 4 can display signed per-record contributions only after the selected
  artifact gate passes.
- The historical `cids-workbench-config-v1` remains as the rejected proposal;
  `cids-workbench-config-v2` is the active policy.
